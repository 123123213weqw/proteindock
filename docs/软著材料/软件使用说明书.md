# ProteinDock 基于深度学习打分的蛋白质-小分子对接平台软件 V1.0
# 使 用 说 明 书

---

## 一、软件概述

### 1.1 软件简介

ProteinDock（软件全称：基于深度学习打分的蛋白质-小分子对接平台软件，
版本号 V1.0）是面向药物设计场景的分子对接计算平台。软件以蛋白质三维
结构（PDB 格式）与候选小分子配体（SDF/MOL2 格式）为输入，通过混合
构象搜索与双通道打分，预测配体在蛋白质口袋中的结合构象（pose）与结
合亲和能，并通过 Web 交互式三维可视化界面展示对接结果。

### 1.2 技术特点

| 模块 | 采用技术 |
|------|----------|
| 经验打分 | AutoDock Vina 式五项物理打分函数（高斯吸引、近距斥力、疏水接触、氢键） |
| 深度学习打分 | E(n) 等变图神经网络（EGNN）pose 重打分，知识蒸馏训练 |
| 构象搜索 | 蒙特卡洛模拟退火（MC-SA）与遗传算法（GA）混合策略 |
| 加速技术 | 0.375 Å 打分网格预计算 + 三线性插值，配体扭转键全柔性 |
| 可视化 | Flask + WebGL（3Dmol.js）交互式三维渲染（cartoon / stick / surface） |
| 部署形态 | Web 平台与命令行（CLI）双模式，支持 GPU 服务器部署 |

### 1.3 运行环境

- 操作系统：Linux（推荐 Ubuntu 20.04+）/ macOS / Windows
- Python 3.8 及以上
- 内存 ≥ 8 GB（蛋白超过 5000 重原子建议 16 GB 以上）
- 依赖库：NumPy、SciPy、RDKit、PyTorch、Flask、Matplotlib
- GPU：可选（NVIDIA CUDA GPU 可用于深度学习模块加速）

### 1.4 软件部署形态

软件部署于实验室 GPU 计算服务器（NVIDIA Tesla V100），通过浏览器
访问 Web 界面使用；同时在服务器本地提供命令行接口供批处理调用。

## 二、软件安装

### 2.1 安装依赖

```bash
cd proteindock
python3 -m venv .venv --system-site-packages
source .venv/bin/activate
pip install -r requirements.txt
```

### 2.2 目录结构

```
proteindock/
├── proteindock/        # 核心计算引擎 Python 包
│   ├── chemistry/      # 元素参数、原子分型、刚体几何
│   ├── io/             # PDB/SDF 解析与口袋检测
│   ├── scoring/        # Vina 式打分、打分网格、混合打分器
│   ├── search/         # MC-SA 与遗传算法搜索引擎
│   ├── dl/             # EGNN 模型、数据集、训练
│   ├── pipeline.py     # 对接流水线
│   └── cli.py          # 命令行入口
├── web/                # Web 平台（Flask 后端 + 3Dmol.js 前端）
├── scripts/            # 数据集构建、软著材料生成脚本
├── tests/              # 单元测试
└── examples/           # 内置示例体系
```

### 2.3 启动 Web 平台

```bash
python -m proteindock.cli web --model models/egnn/best.pt --port 8600
```

浏览器访问 `http://<服务器地址>:8600/` 即可使用。

## 三、Web 平台使用说明

### 3.1 主界面

启动后进入平台主界面，分为三个功能区：

- **左侧 —— 对接任务面板**：选择内置示例或上传文件、设置搜索参数、
  提交任务并查看实时进度；
- **中间 —— 3D 结构视图**：蛋白质与配体对接构象的交互式三维渲染；
- **右侧 —— 对接结果面板**：打分排名表、能量分解图、深度学习模型
  信息与运行统计。

（见图 01_平台主界面对接结果.png）

### 3.2 提交对接任务

**方式一：内置示例**

1. 在「对接任务」面板选择「内置示例」页签；
2. 从示例列表中选择体系（软件自动填入该体系的推荐口袋中心坐标）：
   - EGFR 激酶 / erlotinib（PDB: 1M17）—— 靶向药物厄洛替尼
   - 神经氨酸酶 / 奥司他韦（PDB: 1R9O）—— 抗流感药物达菲
   - 雌激素受体 / raloxifene（PDB: 3ERT）—— 内分泌治疗药物
3. 按需调整搜索参数（见 3.3）；
4. 点击「开始对接」。

**方式二：上传文件**

1. 切换到「上传文件」页签；
2. 分别上传蛋白质 PDB 文件与配体 SDF/MOL2 文件；
3. 可选：填写口袋中心坐标（格式 x,y,z，留空则自动检测）；
4. 点击「开始对接」。

### 3.3 搜索参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 搜索策略 | 混合(GA+MC-SA) / 蒙特卡洛模拟退火 / 遗传算法 | 混合 |
| 独立搜索次数 | 多起点独立搜索的次数，越大越充分 | 8–16 |
| 盒子边长 | 搜索空间立方体边长（Å） | 16–24 |
| DL 打分权重 | EGNN 深度学习分数在最终融合分中的权重 | 1.0 |
| 口袋中心 | 搜索空间中心坐标（Å） | 示例自动填入 |

### 3.4 查看进度与结果

任务提交后进度条实时显示执行阶段（解析输入 → 构建打分网格 →
构象搜索 → 聚类去重 → 深度学习重打分 → 已完成）。典型体系
（2500 蛋白重原子、30 配体原子）在 16 Å 盒子、8 次独立搜索下
约 45–70 秒完成。

完成后右侧结果表列出前 9 个构象：

- **经验分**：Vina 式物理打分（kcal/mol，越低越优）；
- **DL 分**：EGNN 深度学习打分（加载模型后显示）；
- **融合分**：经验分 + DL 权重 × DL 分，最终排序依据；
- **簇**：该构象所代表的 2 Å RMSD 聚类规模。

点击任一行可在 3D 视图中切换显示该构象，能量分解图同步更新。

### 3.5 三维可视化操作

- 鼠标左键拖动旋转、滚轮缩放、右键平移；
- **Cartoon**：蛋白质彩虹着色带状卡通表示（默认）；
- **Stick**：原子棒状表示（观察口袋残基细节）；
- **Surface**：范德华分子表面（观察口袋空腔形状）；
- **重置视角**：恢复初始视角。

（见图 02_原子棒状模式.png、03_分子表面模式.png）

### 3.6 深度学习打分模式

启动服务时指定 EGNN 模型权重（`--model models/egnn/best.pt`）后，
结果表中的「DL 分」列显示等变图神经网络对各构象的能量预测，
「融合分」= 经验分 + DL 权重 × DL 分，右侧面板同时显示模型训练
损失曲线。（见图 04_深度学习打分模式.png）

### 3.7 结果文件下载

每个构象对应结果目录中的 `pose_<rank>.sdf` 文件，最优构象的
蛋白-配体复合物结构为 `complex_best.pdb`，可通过软件 API 接口
`/api/jobs/<任务号>/files/<文件名>` 获取，可直接用 Chimera /
PyMOL 等结构软件打开。

## 四、命令行模式使用说明

### 4.1 执行对接

```bash
python -m proteindock.cli dock \
    -r examples/1m17/protein.pdb \
    -l examples/1m17/ligand.sdf \
    -o out_1m17 \
    --pocket 22.0 0.3 52.8 \
    --box 16 --exhaustiveness 12 --method hybrid
```

输出目录包含 `pose_1.sdf` … `pose_9.sdf`（按融合分排序）、
`complex_best.pdb`（最优复合物）与 `report.json`（完整打分明细）。

### 4.2 训练深度学习打分模型

```bash
# 构建训练数据集(从 RCSB 下载复合物并生成扰动 pose)
python scripts/build_dataset.py --out datasets/dockdata --n-decoys 24

# 训练 EGNN 模型
python -m proteindock.cli train --data datasets/dockdata \
    --out models/egnn --epochs 40
```

训练产物：`best.pt`（模型权重）、`history.json`（训练历史）、
`loss_curve.png`（损失曲线）。

### 4.3 环境自检

```bash
python -m proteindock.cli info
```

打印软件版本与各依赖库版本、CUDA 可用性。

## 五、验证示例

以 EGFR 激酶与 erlotinib（PDB: 1M17）重对接（re-docking）为例：
蛋白质重原子 2511 个、配体重原子 29 个、可旋转键 11 个，16 Å 盒子、
12 次独立混合搜索，用时约 60 秒，排名第一的构象与晶体配体构象的
均方根偏差（RMSD）为 2.54 Å（判定阈值 2.5 Å 附近，质心偏移 1.4 Å），
经验打分 -3.94 kcal/mol，与晶体构象打分（-3.58 kcal/mol）一致，
验证了搜索与打分引擎的有效性。

## 六、常见问题

**Q1：上传蛋白后提示「配体解析失败」？**
配体文件需为标准 SDF/MOL2 格式且含有效化合价；带多组分的 SDF 取
第一个分子。

**Q2：盲对接（不填口袋）结果在表面？**
自动口袋检测基于 LigSite 格点扫描，对浅而开放的口袋可能定位偏差，
建议结合文献口袋坐标或配体类似物位置填写口袋中心。

**Q3：DL 分显示为空？**
未指定 `--model` 或模型文件不存在时自动退化为纯经验打分模式，
属正常行为。

**Q4：结果表多个构象分数相同？**
不同搜索起点收敛到同一能量盆地时聚类为代表元；可增大独立搜索
次数或缩小盒子。
